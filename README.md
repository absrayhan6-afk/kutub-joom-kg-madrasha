# কুতুবজোম ইসলামিয়া কে.জি এন্ড প্রি-ক্যাডেট মাদ্রাসা — ওয়েবসাইট

মহেশখালী, কক্সবাজার। এই ওয়েবসাইটের দুটি অংশ:

| অংশ | ঠিকানা | কারা ব্যবহার করবেন |
|---|---|---|
| **অভিভাবকদের পেজ** | `/` (হোম) | সবাই: রেজাল্ট দেখা, নোটিশ, ভর্তি তথ্য, যোগাযোগ |
| **অ্যাডমিন প্যানেল** | `/admin` | প্রিন্সিপাল ও শিক্ষক (User ID + Password) |

## যা যা আছে

- **রেজাল্ট খোঁজা:** ক্লাস, পরীক্ষা, রোল, রেজিস্ট্রেশন নম্বর ও সাল দিয়ে। বোর্ডের মতো রঙিন মার্কশিট দেখায়, প্রিন্ট বা PDF করা যায়।
- **বছরে তিনটি পরীক্ষা:** প্রথম সাময়িক, দ্বিতীয় সাময়িক ও বার্ষিক।
- **রেজাল্ট প্রকাশ:** প্রিন্সিপাল "প্রকাশ করুন" না চাপা পর্যন্ত কেউ রেজাল্ট দেখতে পায় না। এই নিয়ম ডাটাবেস থেকেই নিয়ন্ত্রিত।
- **বহু বছরের রেজাল্ট সংরক্ষণ:** আগের সব বছরের রেজাল্ট দেখা যায়।
- **GPA ও মেধাক্রম:** বোর্ডের নিয়মে নিজে থেকে হিসাব হয় (৮০+ A+ ... ৩৩-এর নিচে F)। বার্ষিক পরীক্ষায় মেধাক্রম অনুযায়ী নতুন রোল।
- **শিক্ষক লগইন:** প্রত্যেক শিক্ষক শুধু নিজের শ্রেণির নম্বর এন্ট্রি করতে পারেন।
- **হিসাব:** বছরে তিনবার (প্রতি পরীক্ষার আগে)। ভর্তি ফি, মাসিক বেতন ও তিন পরীক্ষার ফি। আদায় এন্ট্রি, বকেয়া সারাংশ, বকেয়া স্লিপ প্রিন্ট, বেতন ছাড়।
- **Archive ও প্রমোশন:** বছর শেষে এক ক্লিকে সব রেজাল্ট সংরক্ষণ, আর সব শিক্ষার্থী বার্ষিক মেধাক্রম অনুযায়ী নতুন রোল নিয়ে পরের শ্রেণিতে।
- **হিসাবের খাত এডিটযোগ্য:** নতুন খাত যোগ, কোন মাস কোন হিসাবে যাবে বদলানো, ফ্রি / অর্ধেক / নির্দিষ্ট % ছাড়। খালি ঘর নিজে থেকে বকেয়া।
- **আইডি কার্ড:** মাদ্রাসার ফরম্যাটে সামনে-পেছনে দুই দিক, ইংরেজিতে। ক্যামেরা দিয়ে ছবি তুললে ব্যাকগ্রাউন্ড নিজে থেকে সাদা হয়। প্রতিটি শ্রেণির কার্ড Adobe Illustrator-এ খোলার মতো ফাইলে (SVG, A4 পাতায় 9টি করে) ডাউনলোড।
- **অফিস / কম্পিউটার লগইন:** শুধু আইডি কার্ড অংশ দেখা যায়।
- **অন্যান্য:** নোটিশ, ভর্তি বিজ্ঞপ্তি, লোগো, ব্যানার ও স্বাক্ষর পরিবর্তন, প্রিন্সিপাল ও শিক্ষকদের ছবি ও মোবাইল, Excel ডাউনলোড, PDF (প্রিন্ট থেকে Save as PDF), সম্পূর্ণ ব্যাকআপ।
- **রেজিস্ট্রেশন নম্বর:** সব শ্রেণির জন্য একটাই ক্রম, শিক্ষার্থী যোগ হলেই নিজে থেকে তৈরি হয়, প্রতি বছর একই থাকে। কেউ বাদ গেলে পরের রোলগুলো এক ঘর উপরে আসে।
- **Excel আপলোড:** পুরো শ্রেণির শিক্ষার্থীর তালিকা Excel থেকে একবারে। বাংলা নাম থেকে ইংরেজি নাম নিজে থেকে।
- **ফলাফলের নিয়ম:** 1–2 বিষয়ে অকৃতকার্য হলে "বিশেষ বিবেচনা" (মেধাক্রম সবার শেষে), 3 বা বেশি বিষয়ে অকৃতকার্য হলে FAIL (মেধাক্রম ও নতুন রোল নেই)। উপস্থিতি (মোট/উপস্থিত/অনুপস্থিত দিন) মার্কশিটে।
- **পরীক্ষার রুটিন:** হিসাব পেজে রুটিন তৈরি/এডিট, প্রতিটি শিক্ষার্থীর জন্য রুটিন + বকেয়া একসাথে প্রিন্ট।
- **অনলাইন ভর্তি আবেদন:** হোম পেজ থেকে ফর্ম পূরণ, আবেদন কোড, অভিভাবকের মোবাইলে PDF; অ্যাডমিনে নোটিফিকেশন, কনফার্ম + PDF, শিক্ষার্থী তালিকায় যোগ।
- **ভর্তি ব্যানার:** হোম পেজের ব্যানারের সব লেখা ও ছবি অ্যাডমিন থেকে বদলানো যায়।
- **সংখ্যা ও মার্কশিট:** সব সংখ্যা ইংরেজিতে, মার্কশিটের সব লেখা ইংরেজিতে।

## বাংলা ফন্ট (সুতন্নি)

ওয়েবসাইট বাংলা লেখায় **SutonnyOMJ** (সুতন্নির ইউনিকোড সংস্করণ) ব্যবহার করে। যে কম্পিউটারে এই ফন্ট ইনস্টল আছে সেখানে সুতন্নিতেই দেখাবে, না থাকলে কাছাকাছি দেখতে Noto Serif Bengali দেখাবে।
সবার মোবাইলেও সুতন্নি দেখাতে চাইলে বৈধ লাইসেন্সসহ `SutonnyOMJ.ttf` ফাইলটি `assets/fonts/` ফোল্ডারে রাখুন।
পুরনো **SutonnyMJ** (বিজয় কিবোর্ডের ANSI ফন্ট) ওয়েবসাইটে ব্যবহার করা যায় না: ইউনিকোড বাংলা লেখা ওই ফন্টে ভেঙে যায়।

## ডেমো মোড

`js/config.js` ফাঁকা থাকলে ওয়েবসাইট **ডেমো মোডে** চলে: নমুনা ডাটা দেখায়, কিছু আসল ডাটাবেসে জমা হয় না।
ডেমো লগইন: `principal` / `demo1234` (শিক্ষক: `teacher` / `demo1234`, অফিস: `office` / `demo1234`)।

## লাইভ করার ধাপ (Firebase, ফ্রি)

1. **Firebase প্রজেক্ট খুলুন:** <https://console.firebase.google.com> → *Create a project* → নাম দিন (যেমন `kutubjoom-madrasha`) → Google Analytics বন্ধ রাখতে পারেন।
2. **লগইন চালু করুন:** *Build → Authentication → Get started → Email/Password → Enable → Save*।
3. **ডাটাবেস তৈরি করুন:** *Build → Firestore Database → Create database* → লোকেশন `asia-south1 (Mumbai)` → *production mode*।
   তারপর *Rules* ট্যাবে গিয়ে এই রিপোজিটরির `firestore.rules` ফাইলের পুরো লেখা বসিয়ে *Publish* চাপুন।
4. **হোস্টিং চালু করুন:** *Build → Hosting → Get started* (ধাপগুলো Next চেপে শেষ করুন)।
5. **ওয়েব অ্যাপ যোগ করুন:** *Project settings (⚙️) → Your apps → `</>`* → নাম দিন → *Register app*। যে `firebaseConfig` দেখাবে সেটা `js/config.js`-এ বসাতে হবে, আর প্রজেক্ট আইডি `.firebaserc`-এ। এই তথ্য গোপন নয়।
6. **স্বয়ংক্রিয় লাইভ করার চাবি:** *Project settings → Service accounts → Generate new private key* → একটি JSON ফাইল ডাউনলোড হবে।
   GitHub-এ এই রিপোজিটরির *Settings → Secrets and variables → Actions → New repository secret* → নাম `FIREBASE_SERVICE_ACCOUNT` → JSON ফাইলের পুরো লেখা বসিয়ে *Add secret*।
   ⚠️ এই JSON ফাইল গোপন। কাউকে দেবেন না, চ্যাটে বা কোডে বসাবেন না। শুধু GitHub Secret-এ রাখুন।
7. এরপর `main` ব্রাঞ্চে প্রতিবার কোড আপডেট হলে ওয়েবসাইট নিজে থেকে লাইভ হবে: `https://<project-id>.web.app`
8. **প্রথমবার প্রিন্সিপাল অ্যাকাউন্ট:** `https://<project-id>.web.app/admin` খুলুন। প্রথমবার "প্রথমবার সেটআপ" ফর্ম আসবে। সেখানে প্রিন্সিপালের User ID ও Password দিন। এটি শুধু একবারই করা যায়।
9. **গুগলে আনা:** <https://search.google.com/search-console> → সাইটের ঠিকানা যোগ করুন → *URL inspection → Request indexing*।

### নিজের ডোমেইন (ঐচ্ছিক)

*Hosting → Add custom domain* → ডোমেইন লিখুন → যে DNS রেকর্ড দেখাবে তা ডোমেইন কোম্পানির প্যানেলে বসান। চালু হতে ২৪–৪৮ ঘণ্টা লাগতে পারে।

## নিরাপত্তা

- অভিভাবকরা শুধু প্রকাশিত রেজাল্ট দেখতে পারেন, তাও সঠিক রোল ও রেজিস্ট্রেশন নম্বর দিলে। সবার রেজাল্টের তালিকা কেউ দেখতে পারে না।
- নম্বর, শিক্ষার্থীর তালিকা ও হিসাব শুধু লগইন করা স্টাফ দেখতে পারেন। হিসাব শুধু প্রিন্সিপাল।
- নিয়মিত *ফলাফল সংরক্ষণ → Full Backup Download* থেকে ব্যাকআপ রাখুন।
